# Alloush System Dashboard

Arabic-first personnel and crew-change dashboard built with React, TypeScript, Vite, Tailwind CSS, Lucide, and Supabase.

## Included

- Overview of employee totals by rig
- Crew-change request form with employee search and filters
- Employee directory with rig selection, search, and contact visibility toggle
- Supabase migration for shared crew-change requests with row-level security

## Configuration

The app reads its Supabase connection from Vite environment variables. Keep local environment files private and do not commit them.
